# Waidwerk – Waffenfachhandel Design-Demo (Seitfix)

Statische Demo-Website (HTML/CSS/JS), fotografiegetrieben, Loden/Messing.
Seiten: index.html · sortiment.html · produkt.html · waffenrecht.html · kontakt.html

Ansehen: index.html doppelklicken.

Umbenennen für einen Kunden: Logo/Name im Header & Footer, Adresse/Telefon, Farben in style.css (:root).
